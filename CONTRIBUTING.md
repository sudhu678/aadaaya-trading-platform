# Contributing

Thanks for contributing to Aadaaya Trading Platform.

1. Open an issue describing a bug, enhancement, or proposed interface change.
2. Create a focused branch and include tests for behavior changes.
3. Keep strategy examples educational, independently authored, and clearly documented.
4. Do not submit private strategy code, credentials, trading records, research exports, or third-party code without distribution rights.
5. Run bootstrap, tests, and secret scans before submitting a pull request.
6. Explain compatibility implications for CLI, API, persistence, and dashboard changes.

Contributions submitted for inclusion are intended to be distributed under the MIT License. Do not include code you cannot license on those terms.
